# Dress Store Backend Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the backend core of the dress store rental app — the Prisma
data model (shared between SQLite and PostgreSQL), the occupancy/
availability business logic, staff auth, and the REST API for clients,
products, and allocations — as a standalone, fully-tested Node/TypeScript
service you can run and `curl` before any UI exists.

**Architecture:** A single Express app backed by Prisma, using Prisma's
driver-adapter API so the exact same model definitions run against SQLite
(local/Electron) or PostgreSQL (hosted) by swapping one adapter, selected
by a `DB_PROVIDER` env var. Business logic (occupancy/availability, status
transitions) lives in framework-free modules under `src/domain` and
`src/services`, tested directly with Vitest; Express routes are thin
wrappers that validate input with Zod and translate domain errors to HTTP
responses via machine-readable error codes.

**Tech Stack:** Node.js + TypeScript 5.9, Express 5, Prisma 7 (with
`@prisma/adapter-better-sqlite3` and `@prisma/adapter-pg`), Zod 4,
Vitest 4 + Supertest, bcrypt + jsonwebtoken for auth.

**Scope note:** This plan covers the backend only — no React frontend, no
Electron packaging, no hosted deployment config, no i18n wiring (that's
frontend work). Those follow as separate plans once this API's contract
is stable. This plan produces working, curl-able software on its own:
by the end you can register a client, register a dress, allocate it,
check it out, and return it, entirely through HTTP calls, with the one
correctness-critical rule (double-booking prevention) hardened by tests
against both SQLite and Postgres.

## Global Constraints

- Availability (`available`/`reserved`/`rented`) is never a stored field —
  it is always derived from `Allocation` rows (design doc, "Data model").
- A `checked_out` allocation occupies `[checkout_date, ∞)` — it keeps
  blocking the product for any future date until a return is recorded,
  regardless of `due_date` (design doc, "Data model" occupancy rules).
  This is the one rule that must never regress.
- `Product.status` only ever holds `active` / `maintenance` / `retired` —
  never an availability value (design doc, "Data model").
- A `Product` or `Client` with any `Allocation` history cannot be deleted
  (design doc, "Data model").
- The occupancy check and the allocation insert happen inside one DB
  transaction (design doc, "Error handling").
- Backend responses use machine-readable error codes, not translated
  prose — the (future) frontend owns translation (design doc,
  "Architecture — i18n").
- Tests: Vitest for unit/integration; the occupancy/availability suite
  must explicitly cover the overdue-still-blocks case, and must also run
  against Postgres before the hosted build ships (design doc, "Testing").
- `Location` has a `locale` field defaulting to `pt-BR`; no other locale
  logic belongs in this backend-core plan (design doc scope boundary).

**Important verified constraints this task encodes:**
- The SQLite connector does not support Prisma `enum` types (validation
  error P1012) — every "enum-like" field below is a plain `String`,
  validated at the application layer instead.
- Prisma does not support scalar list fields (`String[]`) portably across
  SQLite and PostgreSQL — `Product.photos` is stored as a JSON-encoded
  `String` and parsed/serialized in the service layer.
- Prisma 7's `datasource.provider` is fixed per schema file (it cannot be
  chosen at runtime), so this task generates one schema file per provider
  from one shared model source, selected by `DB_PROVIDER`.

```typescript
import type { NextFunction, Request, Response } from 'express'
import { AppError } from './AppError.js'
import { ErrorCodes } from './errorCodes.js'

export function errorMiddleware(
  err: unknown,
  _req: Request,
  res: Response,
  _next: NextFunction,
): void {
  if (err instanceof AppError) {
    res.status(err.status).json({ code: err.code, message: err.message })
    return
  }
  console.error(err)
  res.status(500).json({ code: ErrorCodes.INTERNAL_ERROR, message: 'Internal server error' })
}
```

```typescript
export type AllocationStatus = 'reserved' | 'checked_out' | 'returned' | 'cancelled'

export interface AllocationWindow {
  status: AllocationStatus
  checkoutDate: Date
  dueDate: Date
  actualReturnDate: Date | null
}

interface OccupiedRange {
  start: Date
  /** null means occupied indefinitely (checked_out, not yet returned). */
  end: Date | null
}

function occupiedRange(allocation: AllocationWindow): OccupiedRange | null {
  switch (allocation.status) {
    case 'reserved':
      return { start: allocation.checkoutDate, end: allocation.dueDate }
    case 'checked_out':
      // Occupied until a return is actually recorded, not until due_date —
      // a late return is a real physical conflict, not a plan.
      return { start: allocation.checkoutDate, end: null }
    case 'returned':
    case 'cancelled':
      return null
  }
}

function rangesOverlap(aStart: Date, aEnd: Date | null, bStart: Date, bEnd: Date | null): boolean {
  const aEndTime = aEnd ? aEnd.getTime() : Number.POSITIVE_INFINITY
  const bEndTime = bEnd ? bEnd.getTime() : Number.POSITIVE_INFINITY
  return aStart.getTime() <= bEndTime && bStart.getTime() <= aEndTime
}

export function isOccupiedForRange(
  allocations: AllocationWindow[],
  requestedStart: Date,
  requestedEnd: Date,
): boolean {
  return allocations.some((allocation) => {
    const occupied = occupiedRange(allocation)
    if (!occupied) return false
    return rangesOverlap(occupied.start, occupied.end, requestedStart, requestedEnd)
  })
}

export type DerivedAvailability = 'available' | 'reserved' | 'rented'

export function derivedAvailability(allocations: AllocationWindow[], asOf: Date): DerivedAvailability {
  const occupiedToday = allocations.filter((allocation) => {
    const occupied = occupiedRange(allocation)
    if (!occupied) return false
    return rangesOverlap(occupied.start, occupied.end, asOf, asOf)
  })

  if (occupiedToday.length === 0) return 'available'
  if (occupiedToday.some((allocation) => allocation.status === 'checked_out')) return 'rented'
  return 'reserved'
}
```

```typescript
import type { NextFunction, Request, Response } from 'express'
import { AppError } from '../errors/AppError.js'
import { ErrorCodes } from '../errors/errorCodes.js'
import { verifyStaffToken } from './jwt.js'

export function requireAuth(req: Request, _res: Response, next: NextFunction): void {
  const header = req.header('authorization')
  if (!header?.startsWith('Bearer ')) {
    throw new AppError(ErrorCodes.UNAUTHORIZED, 401, 'Missing or malformed Authorization header')
  }

  const token = header.slice('Bearer '.length)
  try {
    req.staff = verifyStaffToken(token)
  } catch {
    throw new AppError(ErrorCodes.UNAUTHORIZED, 401, 'Invalid or expired token')
  }
  next()
}
```

```typescript
  password: z.string().min(1),
})

authRouter.post('/login', async (req, res) => {
  const parsed = loginSchema.safeParse(req.body)
  if (!parsed.success) {
    throw new AppError(ErrorCodes.VALIDATION_ERROR, 400, 'login and password are required')
  }

  const staff = await prisma.staff.findUnique({ where: { login: parsed.data.login } })
  if (!staff) {
    throw new AppError(ErrorCodes.INVALID_CREDENTIALS, 401, 'Invalid login or password')
  }

  const passwordMatches = await verifyPassword(parsed.data.password, staff.passwordHash)
  if (!passwordMatches) {
    throw new AppError(ErrorCodes.INVALID_CREDENTIALS, 401, 'Invalid login or password')
  }

  const token = signStaffToken({ staffId: staff.id, role: staff.role as 'owner' | 'staff' })
  res.json({ token })
```

```typescript
import { prisma } from '../db/client.js'
import { AppError } from '../errors/AppError.js'
import { ErrorCodes } from '../errors/errorCodes.js'

export interface CreateClientInput {
  name: string
  phone: string
  email: string
  notes?: string
}

export interface UpdateClientInput {
  name?: string
  phone?: string
  email?: string
  notes?: string | null
}

export function createClient(data: CreateClientInput) {
  return prisma.client.create({ data })
}

export function listClients() {
  return prisma.client.findMany({ orderBy: { createdAt: 'desc' } })
}

export async function getClient(id: string) {
  const client = await prisma.client.findUnique({ where: { id } })
  if (!client) {
    throw new AppError(ErrorCodes.NOT_FOUND, 404, `Client ${id} not found`)
  }
  return client
}

export async function updateClient(id: string, data: UpdateClientInput) {
  await getClient(id)
  return prisma.client.update({ where: { id }, data })
}

export async function deleteClient(id: string): Promise<void> {
  await getClient(id)
  const allocationCount = await prisma.allocation.count({ where: { clientId: id } })
  if (allocationCount > 0) {
    throw new AppError(
      ErrorCodes.CANNOT_DELETE_WITH_HISTORY,
      409,
      'Cannot delete a client with allocation history',
    )
  }
  await prisma.client.delete({ where: { id } })
}
```

```typescript
import { AppError } from '../errors/AppError.js'
import { ErrorCodes } from '../errors/errorCodes.js'

export type ProductStatus = 'active' | 'maintenance' | 'retired'

export interface ProductDTO {
  id: string
  locationId: string
  name: string
  description: string | null
  category: string
  size: string
  color: string
  rentalPrice: number
  depositAmount: number
  photos: string[]
  status: ProductStatus
  createdAt: Date
}

export interface CreateProductInput {
  locationId: string
  name: string
  description?: string
  category: string
  size: string
  color: string
  rentalPrice: number
  depositAmount: number
  photos?: string[]
}

export interface UpdateProductInput {
  name?: string
  description?: string | null
  category?: string
  size?: string
  color?: string
  rentalPrice?: number
  depositAmount?: number
  photos?: string[]
  status?: ProductStatus
}

interface ProductRow {
  id: string
  locationId: string
  name: string
  description: string | null
  category: string
  size: string
  color: string
  rentalPrice: number
  depositAmount: number
  photos: string
  status: string
  createdAt: Date
}

function toDTO(row: ProductRow): ProductDTO {
  return {
    ...row,
    photos: JSON.parse(row.photos) as string[],
    status: row.status as ProductStatus,
  }
}

export async function createProduct(data: CreateProductInput): Promise<ProductDTO> {
  const row = await prisma.product.create({
    data: {
      locationId: data.locationId,
      name: data.name,
      description: data.description,
      category: data.category,
      size: data.size,
      color: data.color,
      rentalPrice: data.rentalPrice,
      depositAmount: data.depositAmount,
      photos: JSON.stringify(data.photos ?? []),
    },
  })
  return toDTO(row)
}

export async function listProducts(): Promise<ProductDTO[]> {
  const rows = await prisma.product.findMany({ orderBy: { createdAt: 'desc' } })
  return rows.map(toDTO)
}

export async function getProduct(id: string): Promise<ProductDTO> {
  const row = await prisma.product.findUnique({ where: { id } })
  if (!row) {
    throw new AppError(ErrorCodes.NOT_FOUND, 404, `Product ${id} not found`)
  }
  return toDTO(row)
}

export async function updateProduct(id: string, data: UpdateProductInput): Promise<ProductDTO> {
  await getProduct(id)
  const row = await prisma.product.update({
    where: { id },
    data: {
      ...data,
      photos: data.photos ? JSON.stringify(data.photos) : undefined,
    },
  })
  return toDTO(row)
}

export async function deleteProduct(id: string): Promise<void> {
  await getProduct(id)
  const allocationCount = await prisma.allocation.count({ where: { productId: id } })
  if (allocationCount > 0) {
    throw new AppError(
      ErrorCodes.CANNOT_DELETE_WITH_HISTORY,
      409,
      'Cannot delete a product with allocation history',
    )
  }
  await prisma.product.delete({ where: { id } })
}
```

**Interfaces:**
- Consumes: `prisma`, `isOccupiedForRange`/`derivedAvailability`/
  `AllocationWindow` from Task 4, `AppError`/`ErrorCodes`, `requireAuth`.
- Produces:
  - `createAllocation(input: { productId: string; clientId: string; staffId: string; checkoutDate: Date; dueDate: Date; priceCharged: number }): Promise<Allocation>` — throws `DUE_DATE_BEFORE_CHECKOUT` or `PRODUCT_UNAVAILABLE`
  - `checkOutAllocation(id: string, data: { conditionNotesOut?: string; depositCollected?: number }): Promise<Allocation>` — throws `NOT_FOUND` / `INVALID_ALLOCATION_TRANSITION`
  - `returnAllocation(id: string, data: { conditionNotesIn?: string; depositReturned?: number; actualReturnDate?: Date }): Promise<Allocation>`
  - `cancelAllocation(id: string): Promise<Allocation>`
  - `getProductAvailability(productId: string, asOf?: Date): Promise<'available' | 'reserved' | 'rented'>`

**Why the retry loop below exists:** Postgres's `Serializable` isolation
level (used only when `DB_PROVIDER=postgresql`) can abort one of two
concurrent conflicting transactions with error code `P2034` rather than
silently allowing a race — this is the documented, correct way to use
Prisma's serializable transactions, and the retry loop is Prisma's own
recommended pattern for handling it. SQLite doesn't need this: writes are
already serialized at the file level by `better-sqlite3`.

```typescript
import { Prisma } from '../generated/prisma/client.js'
import { prisma } from '../db/client.js'
import { AppError } from '../errors/AppError.js'
import { ErrorCodes } from '../errors/errorCodes.js'
import { isOccupiedForRange, derivedAvailability, type AllocationWindow, type AllocationStatus } from '../domain/occupancy.js'

const MAX_WRITE_CONFLICT_RETRIES = 5
const ACTIVE_STATUSES: AllocationStatus[] = ['reserved', 'checked_out']

export interface CreateAllocationInput {
  productId: string
  clientId: string
  staffId: string
  checkoutDate: Date
  dueDate: Date
  priceCharged: number
}

function toWindow(allocation: { status: string; checkoutDate: Date; dueDate: Date; actualReturnDate: Date | null }): AllocationWindow {
  return {
    status: allocation.status as AllocationStatus,
    checkoutDate: allocation.checkoutDate,
    dueDate: allocation.dueDate,
    actualReturnDate: allocation.actualReturnDate,
  }
}

export async function createAllocation(input: CreateAllocationInput) {
  if (input.dueDate.getTime() < input.checkoutDate.getTime()) {
    throw new AppError(ErrorCodes.DUE_DATE_BEFORE_CHECKOUT, 400, 'Due date must be on or after checkout date')
  }

  const useSerializable = process.env.DB_PROVIDER === 'postgresql'

  for (let attempt = 0; attempt < MAX_WRITE_CONFLICT_RETRIES; attempt++) {
    try {
      return await prisma.$transaction(
        async (tx) => {
          const existing = await tx.allocation.findMany({
            where: { productId: input.productId, status: { in: ACTIVE_STATUSES } },
          })

          const windows = existing.map(toWindow)

          if (isOccupiedForRange(windows, input.checkoutDate, input.dueDate)) {
            throw new AppError(
              ErrorCodes.PRODUCT_UNAVAILABLE,
              409,
              'Product is not available for the requested dates',
            )
          }

          return tx.allocation.create({
            data: {
              productId: input.productId,
              clientId: input.clientId,
              staffId: input.staffId,
              checkoutDate: input.checkoutDate,
              dueDate: input.dueDate,
              status: 'reserved',
              priceCharged: input.priceCharged,
            },
          })
        },
        useSerializable ? { isolationLevel: Prisma.TransactionIsolationLevel.Serializable } : undefined,
      )
    } catch (error) {
      if (error instanceof Prisma.PrismaClientKnownRequestError && error.code === 'P2034') {
        continue
      }
      throw error
    }
  }

  throw new AppError(
    ErrorCodes.PRODUCT_UNAVAILABLE,
    409,
    'Could not complete allocation due to repeated write conflicts, please retry',
  )
}

async function getAllocationOrThrow(id: string) {
  const allocation = await prisma.allocation.findUnique({ where: { id } })
  if (!allocation) {
    throw new AppError(ErrorCodes.NOT_FOUND, 404, `Allocation ${id} not found`)
  }
  return allocation
}

export interface CheckOutInput {
  conditionNotesOut?: string
  depositCollected?: number
}

export async function checkOutAllocation(id: string, data: CheckOutInput) {
  const allocation = await getAllocationOrThrow(id)
  if (allocation.status !== 'reserved') {
    throw new AppError(
      ErrorCodes.INVALID_ALLOCATION_TRANSITION,
      409,
      `Cannot check out an allocation with status ${allocation.status}`,
    )
  }
  return prisma.allocation.update({
    where: { id },
    data: {
      status: 'checked_out',
      conditionNotesOut: data.conditionNotesOut,
      depositCollected: data.depositCollected,
    },
  })
}

export interface ReturnInput {
  conditionNotesIn?: string
  depositReturned?: number
  actualReturnDate?: Date
}

export async function returnAllocation(id: string, data: ReturnInput) {
  const allocation = await getAllocationOrThrow(id)
  if (allocation.status !== 'checked_out') {
    throw new AppError(
      ErrorCodes.INVALID_ALLOCATION_TRANSITION,
      409,
      `Cannot return an allocation with status ${allocation.status}`,
    )
  }
  return prisma.allocation.update({
    where: { id },
    data: {
      status: 'returned',
      actualReturnDate: data.actualReturnDate ?? new Date(),
      conditionNotesIn: data.conditionNotesIn,
      depositReturned: data.depositReturned,
    },
  })
}

export async function cancelAllocation(id: string) {
  const allocation = await getAllocationOrThrow(id)
  if (allocation.status !== 'reserved') {
    throw new AppError(
      ErrorCodes.INVALID_ALLOCATION_TRANSITION,
      409,
      `Cannot cancel an allocation with status ${allocation.status}`,
    )
  }
  return prisma.allocation.update({ where: { id }, data: { status: 'cancelled' } })
}

export async function getProductAvailability(productId: string, asOf: Date = new Date()) {
  const allocations = await prisma.allocation.findMany({
    where: { productId, status: { in: ACTIVE_STATUSES } },
  })
  return derivedAvailability(allocations.map(toWindow), asOf)
}
```

```typescript
import { prisma } from '../db/client.js'

export function listGoingOut(from: Date, to: Date) {
  return prisma.allocation.findMany({
    where: {
      status: 'reserved',
      checkoutDate: { gte: from, lte: to },
    },
    orderBy: { checkoutDate: 'asc' },
  })
}

export function listDueBack(from: Date, to: Date) {
  return prisma.allocation.findMany({
    where: {
      status: 'checked_out',
      dueDate: { gte: from, lte: to },
    },
    orderBy: { dueDate: 'asc' },
  })
}

export function listOverdue(asOf: Date = new Date()) {
  return prisma.allocation.findMany({
    where: {
      status: 'checked_out',
      dueDate: { lt: asOf },
    },
    orderBy: { dueDate: 'asc' },
  })
}
```

```typescript
import { Router } from 'express'
import { z } from 'zod'
import { requireAuth } from '../auth/authMiddleware.js'
import { AppError } from '../errors/AppError.js'
import { ErrorCodes } from '../errors/errorCodes.js'
import { listGoingOut, listDueBack, listOverdue } from '../services/calendarService.js'

export const calendarRouter = Router()
calendarRouter.use(requireAuth)

const rangeSchema = z.object({
  from: z.coerce.date(),
  to: z.coerce.date(),
})

calendarRouter.get('/going-out', async (req, res) => {
  const parsed = rangeSchema.safeParse(req.query)
  if (!parsed.success) {
    throw new AppError(ErrorCodes.VALIDATION_ERROR, 400, 'from and to query params are required')
  }
  res.json(await listGoingOut(parsed.data.from, parsed.data.to))
})

calendarRouter.get('/due-back', async (req, res) => {
  const parsed = rangeSchema.safeParse(req.query)
  if (!parsed.success) {
    throw new AppError(ErrorCodes.VALIDATION_ERROR, 400, 'from and to query params are required')
  }
  res.json(await listDueBack(parsed.data.from, parsed.data.to))
})

calendarRouter.get('/overdue', async (req, res) => {
  const asOf = req.query.asOf ? new Date(String(req.query.asOf)) : new Date()
  res.json(await listOverdue(asOf))
})
```

```markdown
The hosted build runs on PostgreSQL while local development and the
```
